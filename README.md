# Doando Sorrisos

Página responsiva em HTML, CSS e JavaScript puro, sem dependências de execução.

Abra `index.html` no navegador. Para gerar a versão de publicação, execute `npm run build`; os arquivos ficarão em `dist/`.

Recursos: navegação adaptada a celulares, filtros de materiais, perguntas frequentes, compartilhamento e orientação de participação para download. As ilustrações são locais, em SVG e CSS. As fontes do Google Fonts possuem alternativas locais.

O material recebido é uma referência textual, sem captura de um protótipo. O layout segue as cores, seções e elementos descritos. Não há resultados, contatos ou metas inventados. Antes de divulgar a campanha, a instituição deve validar os textos, a lista definitiva de materiais e os canais de contato. A página não recebe pagamentos, não registra doações e não agenda entregas.
